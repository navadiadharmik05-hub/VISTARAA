# 🛋️ Vistaraa Design Studio — Official Website

The official, responsive website for **Vistaraa Design Studio**, an interior design firm. Built with custom HTML/CSS, responsive typography, and an automated quote request backend powered by **Web3Forms**.

## 📌 Features

* **Custom Portfolio Showcase:** Highlighting interior design concepts, modern aesthetics, and project showcases.
* **Interactive Quote System (`GET_A_QUOTE.html`):** Potential clients can request customized project estimates directly through the website.
* **Serverless Email Backend:** Powered by **Web3Forms** API to instantly dispatch user quote requests to the studio's inbox without requiring a custom Node.js/PHP backend server.
* **Responsive Multi-Page Design:** Modular layout with dedicated stylesheets for homepage, firm overview, and inquiry sections.
* **Custom Assets & Typography:** Locally hosted typography (`fonts/`) and high-resolution portfolio images (`images/`).
